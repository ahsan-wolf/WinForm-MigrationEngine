# 11. The Migrator UI

`tools/migrator-ui` is a local web application that does what the CLI does, for people who prefer a window: it builds the command line from a form, runs it, streams the output, shows the report and starts the generated app. It is a tool of this repository (not the separate demo project) and is built with the project's own library, `@wfm/ui-react`.

## 11.1 What you can do
| Step | In the UI | CLI equivalent |
|---|---|---|
| Choose input and output | WinForms source folder, output folder (folder picker; the output must be outside the repository) | `--source`, `--out` |
| Choose what to generate | **IR only**, **Working app**, **App shell**, **Component viewer** | `ir`, `migrate`, `--appshell`, `--preview` |
| Choose the target | react-app, angular-app (app shell and viewer: React only) | `--target` |
| Scope | entry form, depth (0-3, all), every unit, `/modules` catalog, ignore external projects | `--entry`, `--depth`, `--units all`, `--catalog`, `--no-external-projects` |
| Translation (working app) | translate none / rules / llm, compile gate, contract files and scope | `--translate`, `--compile-gate`, `--contract`, `--contract-scope` |
| Rules and images | images folder, archetype rules file | `--images`, `--archetypes` |
| Run | Run / Cancel; the command line is shown above the button | |
| Follow | Log (live), Report (`MIGRATION_REPORT.md`), Runs (history) | |
| Run the app | Install, Start, Stop, Open in browser, and the manual commands to copy | `npm install`, `npm run dev` / `npx ng serve` |

## 11.2 How it works
The host (`host/`, ASP.NET minimal API on net10.0) references the CLI project only so that `migrator.dll` and the engines land beside it, and starts them as **child processes**: a failure or a cancel never affects the host, and the output is streamed line by line (server-sent events). Generated apps are started with `npm run dev -- --port <free port from 5400>` (React) or `npx ng serve --port ...` (Angular); the host waits for the port, and Stop kills the process tree and the port's listener. The UI (`web/`) is React 18 + TypeScript + Vite and uses `WfGroupBox`, `WfRadioButton`, `WfCheckBox`, `WfComboBox`, `WfTextBox`, `WfListBox`, `WfTabs` and the dialog service (the folder picker is a `dialog.show`). The built UI is served by the host.

## 11.3 Run it
```bash
pwsh tools/migrator-ui/start.ps1        # builds the UI once, starts the host on http://127.0.0.1:5280, opens the browser
```
`ui-library/ui-core` and `ui-library/ui-react` must be built first (see the README of the tool).

## 11.4 Safety and limits
- Loopback only; every POST needs the `X-Migrator-UI` header (no CORS). Only fixed commands run (the migrator CLI, `npm install`, `npm run dev`, `npx ng serve`) and app commands only in generated app folders.
- Output outside the repository, inputs read-only (CLAUDE.md section 0.5).
- No authentication, intended for the developer's own machine. Runs live in memory until the host stops (it stops the dev servers it started).
- Not covered: the `contract` and `backend` commands, LLM options beyond the translate switch.
